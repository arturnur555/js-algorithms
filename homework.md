## Git для новичков (часть 2) — командная работа

- 
1. Создание ветки - git branch <ветка> создаёт ветку; git checkout -b <ветка> создаёт и сразу переключает; git checkout <ветка> переключает на существующую
2. Push - выполняется через git push origin master (main); другие пользователи не увидят ветку до тех пор, пока она не окажется на GitHub; для любой другой ветки — git push origin <ветка>; отправлять изменения регулярно, чтобы не потерять данные.
3. Clone - используется как git clone <адрес>; команда скачивает полную копию проекта; вместе с ней подтягиваются все ветки и их история; адрес берётся по зелёной кнопке Code на GitHub.
4. Pull - сначала git checkout master, затем git pull origin master; pull объединяет fetch и merge
5. Вспомогательные команды - git diff <ветка1> <ветка2> показывает различия; git branch -d <ветка> удаляет ветку; git log выводит историю; git help <команда> открывает справку.

# js-algorithms

Учебный репозиторий: модуль «Алгоритмика».



## Что внутри

- `homework.md` — мои цели на модуль и конспекты статей
- `string-utils/` — 7 функций сравнения строк, реализованных через TDD:
  - `len(str)` — длина строки
  - `isEqual(a, b)` — равенство строк
  - `isNotEqual(a, b)` — неравенство строк
  - `isMore(a, b)` — лексикографически больше
  - `isLess(a, b)` — лексикографически меньше
  - `isMoreOrEqual(a, b)` — больше или равно
  - `isLessOrEqual(a, b)` — меньше или равно
